# Abdulfatah Bahbouh

I make small, read-only desktop viewers for local files. Each one is free, MIT licensed, and works offline without telemetry.

- [LeanDoc](https://abooodbah.github.io/leandoc/): a Word (.docx) viewer for Windows, Linux and macOS. It opens documents without Microsoft Office, never runs macros, and never fetches what a document points to. [Source](https://github.com/abooodbah/leandoc)
- [LeanRows](https://abooodbah.github.io/leanrows/): a large CSV viewer for Windows. It opens CSV, TSV, JSONL and log files too big for Excel; a 1.5 GB CSV with 20 million rows opened with an 18.4 MB peak working set. [Source](https://github.com/abooodbah/leanrows)
- [LeanMark](https://abooodbah.github.io/leanmark/): a Markdown viewer for Windows, Linux and macOS. GitHub-flavored Markdown and Mermaid diagrams render offline. [Source](https://github.com/abooodbah/leanmark)

All three are in the Microsoft Store, and the [Lean Apps page](https://abooodbah.github.io/) lists every install route (winget, Scoop, Homebrew, GitHub Releases).
